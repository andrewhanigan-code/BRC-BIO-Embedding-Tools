# Introduction 
Included in this repo are all scripts used in the NEIU and IIT Corp. project on clustering embeddings generated from neural network models.

# Getting Started
To test the clustering results we created, we recommend using the EmbeddingToolsLite functions. You will need a trained neural net model, and a set of images to test on.
